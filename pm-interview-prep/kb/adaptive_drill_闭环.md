# Adaptive Drill 闭环（评分→诊断→推送）

> 本模块把 T1–T5 任务剧本升级为「**评分 → 诊断 → 推送**」自适应闭环。
> 驱动源：`state_A-F.md`（人设状态机当前等级）。对**高**风险维度自动推送专项追问；复盘后回写状态，下次 drill 自动调整。
> 参照：`noamseg/interview-coach-skill` 的 adaptive drill 决策树（§1.3）。

---

## 一、Drill 决策树（输入 state_A-F → 输出推送集）

读取 `state_A-F.md` 的「状态总览」。对每个等级 = **高** 的维度，按下方映射推送；等级 = 低/中 的维度**跳过**（不重复练）。

### A 决策深度 / 边界感（高）
推送 3 类 drill：
1. **PRD 一级目录默写**（来源：速记卡 1）→ 指令：「不看书，默写出 PRD 标准一级目录（需求背景→目标用户→数据分析→产品方案/字段规则→排期开发→验收），卡住就说」。
2. **需求方法 5 类追问**（来源：速记卡 4/5）→ 指令：「给一道开放题——'100 条客户需求怎么组织分类排优先级'，用 调研真伪(toB/toC)→优先级模型(价值-成本/RICE)→对齐资源→MVP 验证 的框架答，不能只说 AI 工具」。
3. **storybank 卡3「决策边界」反追问**（来源：storybank 卡3 百度周结）→ 指令：「为什么设 60 天准入门槛？为什么用三层数据分流而不是全量周结？讲清你做了什么决策、边界在哪」。

### E 学习能力 / 深度（高）
推送 3 类 drill：
1. **俞军公式脱口**（来源：速记卡 2）→ 指令：「脱口俞军价值公式，并解释每个变量；再说出 Kano / AARRR / Y 模型各自解决什么」。
2. **读书核心 1 句 drill** → 指令：「挑你读过的一本产品/商业书，用 1 句话讲清它改了你的哪个认知，不能'读了一半'式回答」。
3. **方法论深度反追问** → 指令：「面试官追问'你这个模型真用过了吗、举个落地的例子'，用真实经历接住，不空谈」。

### 通用 fallback（其他维度若升为「高」）
- 取该维度对应的模块（B→数据口径五要素 / C→展现态心法 / D→动机三层 / F→业务双轴轴 B）+ 1 道反追问。
- 例：F(高) → 「用 1 分钟讲清面试公司的商业模式 + 你项目卡在它价值链哪段」。

## 三、闭环协议（mock / 真实面试后）

```
读 state_A-F → 对「高」维度推送 drill（本轮 3–5 题）
→ 用户作答 → Skill 评分（5 分制，锚定维度）
→ 诊断：哪维仍弱 / 哪维已稳
→ 回写 state_A-F（升/降级 + 证据 + 刷新日期）
→ 下次 drill 据新状态自动调整侧重
```

**回写示例**（高仙一面后已落地）：A 中→高（PRD 卡壳）、E 中→高（俞军读一半）；B/C/D/F 稳=低。下次 T6 自动先推 PRD 默写 + 俞军公式。
