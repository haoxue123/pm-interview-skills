# 面型库（中央预测资产 · 每场复盘强制回流）

> **来源**：真实面试复盘反哺（高驰 / 领格 / 货拉拉 / 趣丸 / 极客跳动 / 全民K歌 TME / 钛动）。
> **用途**：面试前预测面型、面试中开场 2 题实时检测并转向、复盘后回流新面型。
> **定位**：本库 = skill 的「面型预测中枢」，把"押能力结构不押题目"落到可操作的**面型级别**（考法分类学）。

---

## 一、为什么要有面型库（第一性原理）

- 面型（面试官用什么方式考你）是准备方向的**第一变量**。
- 面型押错 → 整包准备错位（全民K歌：押广告专业题，实际开放题思维面，专业准备全盘落空）。
- 但面型**事前大多不可知** → 所以面型库有两个用途：① 已知时精准匹配；② 未知时用"通用包 + 实时检测转向"兜底。
- 面型库**不是押题**，是"考法分类学"——存的是**考法模式**，不是具体题目。

---

## 二、已知面型（4 + 1）

### 面型 A · 专业深挖面
- **特征信号**：深挖简历项目 / 业务细节；追 AB 实验、数据口径、决策原因；"为什么这样决策"。
- **考题模式**：项目 STAR 深挖、数据口径压力测试、业务链路拆解。
- **准备策略**：项目 deep-dive 全备（背景 → 目标 → 动作 → 结果 → 指标 → 难点 → 权衡 → 再来一次）；P0 数据口径闭卷。
- **真实案例**：高驰、领格卓越、**得物（2026-09-10）**。
- **🔴 子模式「口径考官型」（得物 2026-09-10 复现并强化）**：这类面试官**不考你知不知道，考你讲的东西是不是真做过、真想清楚过**——先用一个开放问题让你自己展开（"你当时碰到什么问题"），然后顺着你讲的每个名词往下戳（"流失率是什么口径""活跃度是什么活动""怎么设计的实验"）。90% 火力压在具体指标口径（流失率/活跃度/CTR 参照系/结算周期）+ 实验设计上，几乎不考动机/行为题，仅结尾反问。**准备包"企业速览/AI 认知/五段式/兑付矩阵"命中率≈0，只考 D2/D3 项目深度** → 纯专业深挖场必须把"简历每个数字的三层追问预案（成效→来源→对照基准）"顶到 60%，公司/岗位认知压到 40%。**最贵失分**：半懂时硬下定义且前后自相矛盾（得物题 8 把流失率定义成"含活跃度"与题 7 并列打架），直接打在"逻辑思维"栏——比"不知道"更扣分。应对铁律：半懂先划边界、再给能说的、立刻转。

### 面型 B · HR 行为面
- **特征信号**：动机、稳定性、行为题、文化匹配；"为什么选我们""能实习多久"。
- **考题模式**：自我介绍、动机三层、行为 STAR、稳定性确认。
- **准备策略**：动机话术、稳定性话术、行为题故事库。
- **真实案例**：趣丸、极客跳动。
- **相对评估规律（2026-08-04 趣丸 HR 二面失败反哺）**：HR 面是**相对评估非及格线制**——"答得过去、没翻车"≠"能过"。房间里无负面信号也可能落选，因为 HR 在竞争性池里比的是**谁的 commitment 信号更 standout**。失败归因（推测）：①意愿度/独占性感知弱——被问"有其他 offer 吗"时暴露多选项（深圳+广州并行）、意愿度理由仅"其他非 AI"对比（无趣丸专属锚点）；公司了解题亲口说"第一次接触/现在用得少了"；②稳定性感知弱——实习时长模糊（"3-4 个月以上"）、秋招与实习并行。→ **准备动作**：a) 被问多选项时诚实但克制，立刻拉回"趣丸是我优先级最高，因为 XXX 具体对口"，不强调"都在推进"；b) 公司了解题即使真实用得少也要补兴趣锚点（"发现千音短剧出海 AI 译制成本降 90% 正是我想深耕的"）；c) 时长/秋招题给确定锚点；d) 动机/反问环节植入"入选后前两周目标=把 AI 内容 workflow 从 0 跑通"的 commitment 一句话。**本场不降级 A–F**（业务面已验能力，失败是意愿度感知+竞争，非能力崩盘）。

### 面型 C · 温和深挖面
- **特征信号**：稳定确认 + 温和深挖，压力低；反复确认"能不能稳定实习"。
- **考题模式**：自我介绍 + 稳定性 + 温和项目深挖。
- **准备策略**：稳定性话术 P0 + 项目温和深挖。
- **真实案例**：货拉拉（失败后归因 = 非能力因素：营销实习经历少）。

### 面型 D · 开放题思维面
- **特征信号**：**明确"不聊实习"** + 两个开放式问题考底层思维（用户视角观察力 + 逻辑思维）。
- **考题模式**：广告体验最好的 C 端产品、50 万创业等开放题；不考专业。
- **准备策略**：用户视角案例库（备 3 个广告体验好 / 差案例）；审题复述习惯；框架先行；**不备专业题清单**（命中率≈0）。
- **真实案例**：全民K歌（TME）。失败根因 = 押广告专业题导致空转。

### 面型 E · 带教实操试用面
- **特征信号**：面试官 = 未来业务带教，年龄可能比你还小；权力距离低，像同级协作试用；重"好不好带 / 基础工具熟不熟 / 是否好带"。
- **考题模式**：基础工具题（Excel / SQL / 网盟术语）+ 日常运营理解 + 稳定性 + 责任心。
- **准备策略**：基础工具闭卷（网盟 / GA4 兜底）；把"责任心 + 主动优化重复工作"顶到 P0；展示 coachability；语气对等别端着。
- **真实案例**：⚠️ **原标"钛动科技（年幼带教=唯一面试官）"已被证伪**——2026-08-04 钛动实际是**双面试官资深 PM 专业面**，用户事前口述"年幼带教/only one"信息失真。面型 E 至今**仍缺一个经核实的真实案例**，请勿再把它当成已验证案例。判断面型 E 的可靠信号应是"面试官当场自述身份=你将来的带教"或"往届面经确认"，而非用户/HR 口头声称。

> **⚠️ 红线（2026-08-04 钛动复盘新增）**：**用户 / HR 口述的"面试官身份 / 轮次 / 面型"属低置信信息，不能覆盖反脆弱默认。** 当它和 JD / 薪资信号矛盾时（如实习生岗 200–250/天却号称资深带教、或"only one"实际双面试官），必须二次确认，或直接按"能力结构通用包"准备，绝不锁死某面型专项包。详见 `面试准备_信息完备度自检清单.md` §三补充。

### 面型 F · 业务负责人面（"前 1/3 专业 + 后 2/3 人"型）🆕（2026-09-11 xTool 复盘新增）

- **特征信号**：**面试官在前 1/3 时间用 8 道左右专业题把简历快速过一遍，确认项目真实性后，剩余一半以上时间全部转向通用行为与自我认知题。** 全场的专业题**不考方法论、不考数据口径、不考实操、不考开放设计**——只考"这个项目是不是你自己做的"。
- **识别信号（★ 最关键）**：面试官问完"做多久 / 几个人 / 谁带你"这类**背景验真题**后，**不再往技术纵深追**，而是转向"读研吗 / 职业规划 / 优劣势 / 工作风格 / 困难 / 期待"。**一旦出现这个转向，说明技术段的信息采集已经结束**，后面考的是"你是个什么样的人"。
- **考题模式**：项目 deep-dive（3–4 题/项目）+ 通用行为题 12 题左右（读研 / 职业规划 / 优劣势 / 一致性追问 / 工作风格 / 实习困难 / 实习期待 / 公司了解 / 时长 / 籍贯 / 秋招压力 / 前司转正 / level 比较 / 名校观感）+ 反问。
- **准备策略（与"技术深挖型 AI 面"相反）**：
  1. **通用行为题 8 类弹药库（P0，见 `kb/模块_通用行为题弹药库.md`）** —— 这类面试里它占半场。
  2. **自我定位类问题必须平视**：承认学历劣势（用事实句）→ 立刻转"我做过什么"（事实句）→ 落在可控的事上。**不许拿名校当比较靶位，不许自我贬低。**
  3. **公司了解按"三层口头版"**（做什么 → 在什么位置 → 为什么现在要做我要做的那件事）；
  4. **主动性叙事**：这类面试官极看重"自己找题"。准备"我主动提出的 / 我自驱做的"素材（如"AI 提案这个需求是我自己提出来的，不是领导派的"）。
  5. **技术段要主动给"参与度量化"**：被设问句诱导（"也是别人带你做的吧"）时**不要顺台阶下滑**，据实报参与度（本项目 80–90%、那个项目 50–60%）——这是最便宜的建立可信度动作。
- **真实案例**：创客工场 xTool（2026-09-11，51 分钟，结果通过）；**深圳爱莫科技（2026-09-15，28 分钟，业务负责人面，结果待出）**；**深圳点猫科技·编程猫（2026-09-15，43 分钟，业务负责人面，结果待出）**。xTool 25 题里专业题仅 8 题、通用行为题 15 题；准备包把 80% 篇幅给了业务知识 + AI 认知，**命中率接近零**。爱莫场专业段（题 2–4）快速验真后，重心压到 **AI 工具实操（题 5–7、题 9）+ 一段陌生领域理解测试（题 10 CAR-T）+ 反问业务摸底（题 11）**，同样**全程未问动机/时长**。编程猫场专业段火力集中在**调研方法论六轮深挖（题 4–8）+ 个人 agent 项目（题 17–20）**，后 2/3 全是人与认知题，未问动机/时长。
- **同族案例（共同点：面试官真正判断的是"这个人靠不靠谱、会不会来、能不能自己找活干 + 会不会用 AI 干活"）**：iScreen（不考动机，只考产品拆解与创意）、趣丸 HR 二面（纯行为面）、xTool（专业过一遍后大段考人）、**爱莫科技（专业验真后大段考 AI 工具实操 + 跨域理解 + 业务归纳）**。
- **🆕 同族新信号（爱莫 2026-09-15 回流，编程猫 2026-09-15 二次实锤）：AI 产品岗的「AI 工具广度」是隐藏权重项**。爱莫面试官特意点名 ChatGPT / Claude Code 问"接触过最牛的工具吗"，候选人只报一个工具（WorkBuddy）且把没用过说成"被封了/用不了"像借口 → 在 JD 明写 AI Agent/AI Coding 的岗上是维度级缺口。**编程猫场（同日）题 9 被追"现在用什么 AI"时答"回学校只用 WorkBuddy，其他高端都没用了"，与爱莫完全同源**——两场连续命中 ⇒ 该弱项从单场发现升级为跨场稳定规律。→ 业务负责人面若为 AI 应用/产品岗，准备包须含"至少实测 1 个前沿 agent + 我和 AI 怎么协作的方法论话术"，杜绝借口措辞；且**反问环节是 D' 匹配点最佳出口**（爱莫题 11、编程猫题 25 均听到岗位核心词未回扣自身经历，错过最强锚点）。
- **核心启发**：**AI 岗的面试官一样会花一半时间问"你是什么样的人"。** 别因为"AI 产品岗"这个标签就把准备资源全押在 AI 认知与业务知识上。

### 面型 G · 上级/负责人复核面（"复议 + 验证"型）🆕（2026-09-12 xTool 二面准备新增 · **预测，待 2026-09-14 后回填验证**）

- **触发场景**：二面 / 终面前的负责人面，面试官是**一面面试官（直属业务负责人）的上级**。
- **特征**：① 权责从「筛」变「定」（有决定权或否决权）；② 专业题一问带过（"你那个 X，简单说说"），**不重新深挖**；③ 时间偏短（常见 15–30 分钟）；④ 重心在**动机真实性 / 稳定性 / 成长性 / 自我认知**；⑤ **反问权重最高**，是展示判断力的主要窗口。
- **他的三个判断**：这个人**靠不靠谱**（真实性与边界感）、我**想不想要**（动机与稳定性）、带起来**费不费劲**（成长性）。
- **隐藏结构（最重要）**：**他的决策依据里有一大部分来自一面面试官**。所以本场第一要务不是重讲项目，而是**主动把一面的短板补上**——尤其复盘里判为弱题的方向。
- **准备重点**：① 动机建在**公司处境**上（三层口头版：做什么 → 什么位置 → **为什么现在**），不是建在自己处境上（秋招压力 / 双非 / 前司没转正）；② **稳定性三连主动说**（时长 / 秋招 / 地点），不等问；③ 自我定位题**平视**，不拿名校当靶位、不自我贬低；④ 反问 = 两问了解 + 一问表态。
- **⚠️ 警惕同场（+1 也在场）**：部分公司把「+1 和 +2 一起面」放在这一轮（xTool 同公司 2025-09 公开面经即写：「第三轮 +1 和 +2 一起面，主要 +2」）。→ **所有口径必须与一面完全一致**——尤其参与度数字，**一面主动降过的不许升回去**。
- **反例警示（推测）**：xTool 一面把 80% 篇幅给了业务知识 + AI 认知，实际考的是"你是什么样的人"；上级面会把这个比例推得更极端。

## 三、面型实时检测四问（开场 2 题内）

1. **他聊实习 / 项目深挖吗？** 聊 → A / C；不聊 → D。
2. **他考开放思维 / 用户视角吗？** 考 → D。
3. **他问动机 / 稳定性 / 行为吗？** 问 → B / E。
4. **他验基础工具 / 日常运营吗？** 验 → E（带教面）。
5. 🆕 **他专业题问得浅（只核验"谁做的/做多久"），且 20 分钟后开始问"读研/规划/优劣势"吗？** 是 → **F（业务负责人面·前后两段型）**。
6. 🆕 **他是「一面面试官的上级」吗（二面 / 负责人面 / 终面）？** 是 → **G（上级复核面·复议验证型）**：弃专业纵深，切「动机 + 稳定性 + 自我认知」，反问按三条准备。

检测后立刻切换对应「转向剧本」（见 §四）。

## 四、转向剧本（面型误判时急救）

- **误判为专业面、实际是开放题思维面**（全民K歌反例）：开场若面试官说"不聊实习" → 立刻切"用户视角开场"（"我平时作为用户 + 准 PM 喜欢观察产品，比如…"），弃用专业题清单。
- **误判为开放题、实际是专业深挖**：被追"为什么这样决策" → 切项目 deep-dive（"在 XX 场景下，由于 XX 约束，所以 XX 更优"）。
- **误判为专业面、实际是带教面**：被验基础工具 → 弃战略深度，切工具闭卷 + 责任心话术。
- **误判为专业深挖面、实际是"前后两段型"（面型 F）**：开场专业题问得很浅（只核"谁做的/做多久"）→ **别主动往技术纵深钻**（面试官没打算深挖，硬钻反而显得不懂场面）；立刻把心态切到"通用行为题"频道，并**主动做两件事**：① 主动报项目参与度量化（80–90% / 50–60%），把真实性提前关闭；② 主动给"我主动提出/自驱做的"素材，回应这类面试官最看重的主动性。
- 🆕 **误判为专业深挖面、实际是「上级复核面」（面型 G）**：面试官只说"你那个项目简单说说" → **别展开六大模块**，立刻切 60 秒版；讲完把话头递回去（"细节一面聊过，这次我想多了解您这边"）。
- 🆕 **被设问句诱导时的通用动作**：面试官用陈述句（"这个也是别人带你做的吧"）而非疑问句时，**大概率是在测你会不会虚报**。正确动作 = 据实修正或主动降级自己的贡献，**绝不顺着台阶下滑**。这个动作一次就能把整场的可信度抬起来。

## 五、回流规则（每场复盘必做）

- T3 复盘 §2 / §5 必须判定本场面型，并回流到本库（新增 / 修正特征信号 / 补充案例）。
- 新面型出现 → 加进 §二，并在 §9 三防火墙 / L5 否决层补防火墙案例。
- 面型误判 → 在 `真实面试记录总览.md` 标"面型误判"信号，回流本库作为反例（全民K歌即经典反例）。
