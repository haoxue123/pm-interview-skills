# 速记卡：PM 基本功与经典方法论（必背）

> 来源：高新一面（2026-07-27）真实翻车点复盘。
> 定位：storybank 管「项目故事」，本卡管「基本功 / 方法论」——两者并列，面试前都要过一遍。
> 用法：像「屠夫拿刀杀猪」一样肌肉记忆，不能临场说「我忘了」。

---

## 卡 1｜PRD 标准一级目录骨架（PM 基本功，必背）

写一份 PRD，一级目录建议：
1. **需求背景**：为什么要做（业务问题 / 用户痛点 / 数据佐证）
2. **目标用户 / 角色**：谁用（toB 客户 / toC 用户 / 内部交付团队）
3. **目标与指标**：成功标准（北极星 + 过程指标，带口径）
4. **数据分析**：现状数据、规模、ROI 测算
5. **产品方案**：核心流程、功能点、字段 / 接口规则
6. **排期与资源**：开发 / 算法 / 测试依赖，里程碑
7. **风险与验收**：边界 case、灰度方案、上线验收标准

> 口诀：背景→用户→指标→数据→方案→排期→验收。候选人现场卡壳即因只写不默，需反复脱稿默写到「像拿刀」。

## 卡 2｜经典方法论速记（被反追问能脱口 1 句核心）

| 模型 | 核心一句话 | 适用题 |
|---|---|---|
| **俞军产品价值公式** | 用户价值 = (新体验 − 旧体验) − 替换成本 | 「PM 核心价值」「为什么做这个功能」 |
| **Kano 模型** | 基本型/期望型/兴奋型，先做基本与期望 | 「需求优先级」「功能取舍」 |
| **AARRR** | 获客→激活→留存→营收→自传播 | 「toC 用户提升」「增长」 |
| **Y 模型** | 目标用户—场景—问题—被掩盖的真实需求—解决方案 | 「挖真需求」「100 需求整理」 |
| **MVP** | 最小可行产品，先验证再扩大 | 「百度周结先筛低成本高收益业务」 |

> 读任何方法论书，**合上书必须能说出那 1 句核心**，否则等于没读（高新一面俞军翻车即此）。

## 卡 3｜产品经理的核心价值（标准答案，可嵌入）

1. **定义真问题**：在客户 / 运营 / 技术 / 老板的多方声音里，挑出真正该做的方向。
2. **连接需求与商业**：把用户价值翻译成可落地的业务增长（不是只画原型）。
3. **统筹落地**：对齐开发 / 算法 / 交付资源，把框架变成上线产品。
4. **驱动迭代**：用数据验证假设，持续优化。

> 候选人现场答得偏「落地带动收入」——可保留，但需补「定义问题 + 统筹多方」两环才完整。

## 卡 4｜100 条需求怎么整理（需求池管理框架）

被问「客户扔来 100 条需求，怎么组织、分类、排优先级」时，用这个骨架：
1. **调研真伪**：客户提的不都是真需求（如「页面丑」本质是 ROI 没满足），先访谈挖真问题。
2. **分类**：按 toB / toC、按业务线、按用户角色切分。
3. **优先级模型**：
   - 价值–成本矩阵（高价值低成本的先做）
   - 或 RICE（Reach 触达 / Impact 影响 / Confidence 信心 / Effort 成本）
4. **对齐资源**：与 leader / 算法研发确认可行性，不是全做。
5. **MVP 验证**：先做最小方案上线测效果，显著再扩。

> 现场答得散（只给粗框架无模型），补「价值-成本 / RICE」即升级。

## 卡 5｜需求分析方法论清单（不要只准备「AI 工具」）

当被问「你用什么方法做需求分析 / 用户洞察」时，除 AI 工具外，必须能说：
- **用户访谈**：结构化 1:1，挖「说出来的」背后的「真实任务」
- **数据分析**：漏斗 / 留存 / 同比环比，用量化定位问题
- **竞品拆解**：功能 / 商业模式 / 交互对比，找差异化
- **影子观察（Shadowing）**：跟交付 / 售后一天，看真实痛点（高新岗位尤其相关）
- **问卷 / 埋点**：规模化回收行为数据

> 高新一面真实面试官强调「去现场、去交付、去售后才有发言权」，影子观察法直接呼应。

## 卡 6｜个人资产卡（可嵌入动机 / 优缺点 / 行为题）

- **马拉松（跑步）**：= 长期主义 + 抗压 + 目标拆解能力（训练期一周四五练，15/5/10 km 渐进）。
  - 用法：被问「优缺点」「为什么能耐得住枯燥」时，用马拉松佐证「习惯长期、耐受重复」。
- **WorkBuddy 实践（meta 但真实）**：自己用 WorkBuddy 设 skill / 智能体做行业调研、爬取信息。
  - 用法：被问「用什么 AI / 怎么主动学习」时，作为「AI 产品实践 + 主动学习」的 live 证据（真实面试已自然说出，可固化）。
