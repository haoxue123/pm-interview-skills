# 模块 · 开放题选材纪律（v0.28 新增）

> **为什么要单独立这个模块**：两场面试的弱题 1，性质完全相同。
> - **iScreen（2026-09-09）弱题 1**：照片组件创意题——**把"创意"答成了"流程"**，且与上一题骨架高度重复。官方否决点："内容玩法的创意想法与岗位需求有差距。"
> - **xTool（2026-09-11）弱题 1**：优势劣势题——**在最强项目上自曝流程不严谨**，且精准命中面试官自己给出的用人标准；紧接着的一致性追问又主动撤掉台阶。
>
> **共同点：这两场都是"准备充分但选材失当"——不是知识缺口，是开放型问题上的内容选材/形态失败。**
> 知识可以临时背；**选材是一种判断力，必须在答题前有一套 checklist。**

---

## 一、什么是"开放题"

面试官不给你限定回答范围，只给你一个**任务形态**，让你自己决定往里装什么。典型：

- **自我评价类**：优势劣势 / 你是什么风格的人 / 你怎么评价自己 / 你最大的成长是什么
- **创意设计类**：设计一个 X / 想一个玩法 / 给一个创意 / 如果让你做你会怎么做
- **价值观类**：你最看重什么 / 你怎么看加班 / 你理想的团队是什么样
- **归因类**：你觉得自己为什么能拿到这个机会 / 你觉得这段经历最大的收获是什么

**为什么这类题最容易失分**：因为没有正确答案，所以面试官看的是**你选了什么来讲**。选材本身就是在回答"你是个什么样的人"。

## 二、自我评价类 · 选材三问（答题前必跑）

**你要讲的那个案例，必须同时通过这三问。**

### 问 1 · 这个案例会不会反噬我最强的项目？

如果你的劣势案例来自你最强的那个项目，**面试官会重新评估那个项目的归属**。

**xTool 反例**：
- 题 2 刚说完："我主导 workflow 标准化流程设计，拆解为六大模块；我定义各模块 Prompt 基本规则；推动跨部门协作完成平台搭建。"
- 题 13 紧接着说："在做品牌智能提案的时候，没有跟业务沟通他们具体怎么做提案的步骤，只是把过去的文档翻出来，自己就用 AI 跑了一个方案，这个方案其实是不合标不合规的。"

**同一个项目，前一段是"我主导"，后一段是"我没搞清楚"。** 面试官自然会问：那 80–90% 参与度到底参与到了哪一层？

→ **规则：劣势案例应来自一个"不是你的招牌"的项目或情境。**

### 问 2 · 这个案例会不会命中目标 JD 的核心能力要求？

如果你的劣势，正好是面试官在这份 JD 里最看重的能力，**你在用自己举证对方的担忧**。

**xTool 反例**：面试官在反问环节亲口说用人标准是：
> "需要能**摸到**这个需求的业务需求"

而候选人的劣势案例本质就是"**没摸到业务需求**"。

→ **规则：答题前，先把目标 JD 的核心能力要求抄一遍；劣势案例必须避开它们。**

**可用替代方向**（后果可控、反思深、不命中核心标准）：
- 上手新业务前期偏慢（→ 配"找 key person 一次性问清链路"的方法）
- 太急着出结果，先动手后理解场景（→ 配"先搞清产物被谁在什么场景下用"的判断标准）
- 想一次做全、范围铺太大（→ 配"先验证可行性再扩范围"的收敛习惯）

### 问 3 · 这个案例会不会被追问成"一致性问题"？

**自我评价题的必然后手是一致性追问**："那你日常也这样吗？" / "其他项目也有这个问题吗？"

如果你讲的是一条**习惯性**的劣势，这个追问会把你逼到墙角。
如果你讲的是一条**情境性**的劣势（新业务、新环境、特殊阶段），这个追问就是你展示"我已经改进了"的机会。

→ **规则：优先选情境性劣势，不选习惯性劣势。** 并且**提前准备好一致性追问的答法**（见本模块 §四）。

## 三、创意设计类 · 选材三问

### 问 1 · 我的第一句话是一个**具体点子**，还是**一个流程**？

**iScreen 反例**：被要求"设计一个跟照片相关的桌面组件"，候选人给出了需求分析→竞品→上线的流程，**没有给出一个具体的点子**。

→ **规则：创意题第一句必须是"具体点子" = 场景 + 用户 + 情绪价值。** 流程放后面当补充，不能代替点子。

### 问 2 · 这个点子跟上一题是否同构？

**iScreen 反例**：两道设计题（通用组件 / 照片组件）用同一套骨架答了两次——这大概率是面试官的**对照实验**（看你会不会拿一个模板糊过去）。

→ **规则：连续两道设计题，必须换入口。** 第一题的入口是"场景痛点"，第二题就换成"用户原话"或"一个具体的物理动作"。

### 问 3 · 我给的是"好玩的东西"还是"合理的功能"？

**iScreen 官方反馈**："对于**内容玩法的创意想法**和岗位的需求之间存在一定差距。"

→ **规则：凡 JD 含"创意 / 玩法 / 内容"字样，准备包里必须含「创意生成肌肉训练」，不能只给逐字稿和知识框架。**（训练包见 `[工作区]/记录/内容玩法创意能力训练包.md`）

## 四、识别"给你台阶的题"（★ 与自我评价类强绑定）

有一类追问，面试官是在**给你台阶**——他想让你把某个负面标签限定在具体情境里。**正确动作是"切开"，不是"合并"。**

| 面试官问法 | 台阶是什么 | 正确动作 | 错误动作 |
|---|---|---|---|
| "你日常的学习当中，你认为你也是这样的吗？" | 把"粗心"限定为工作情境 | **切开**：工作上出这个问题的原因是 X，日常我其实是 Y | **合并**："我日常也这样" → 标签从 badcase 升级为人格 |
| "是不是只是这一次项目比较特殊？" | 把失败限定为个案 | **切开**：这次特殊在哪 + 我的常规做法 | 承认这是常态 |
| "你在 X 应该不止做了这一件事吧？" | 给你机会补全信息 | **补全**：另外那段时间我做了什么 | 只答"我挑了参与最深的一个讲" → 留下信息黑洞 |

**xTool 反例（题 14，本场唯一的组合失分点之一）**：
> 面试官："你刚刚觉得你的劣势，你是在工作当中可能犯了这样的一个错误，但是你日常的学习当中，你认为你也是这样的吗？"
> 候选人："我日常生活中的话，我可能也是会，可能自己也是生活可能会比较散吧……活得比较散……思想还是什么都会比较偏自由。"

**面试官主动给了台阶，候选人主动把它撤了。**

**识别信号**：追问里出现「**也是**」「**都**」「**平时**」「**是不是只是**」这类词 → 大概率是在给你台阶 → **先想"怎么把这件事限定在一个情境里"再回答**。

## 五、自检清单（准备完成后逐条打勾）

**自我评价类**
- [ ] 劣势案例**不来自**我的招牌项目
- [ ] 劣势案例**没有命中**目标 JD 的核心能力要求
- [ ] 劣势是**情境性**的，不是**习惯性**的
- [ ] 优势段**独立成立**（把劣势段整个删掉，优势段单独听仍成立）
- [ ] 一致性追问的答法里，**必须有明确的"不是"**（把工作状态和人格状态切开）

**创意设计类**
- [ ] 第一句话是一个**具体点子**（不是流程/框架）
- [ ] 跟上一题**不同构**（入口不一样）
- [ ] 点子带**情绪价值**，不只讲"功能合理"
- [ ] 如果我连续被问两道设计题，第二道**换入口**

**通用**
- [ ] 答题前，我已经把**目标 JD 的核心能力要求**抄过一遍
- [ ] 我的所有回答里**没有**"我们双非""挺可恶的""活得比较散"这类情绪化或自我贬低的表述
