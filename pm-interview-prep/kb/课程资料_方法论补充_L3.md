## ★ 新增原子单位（skill 当前缺失）

### L3-N1 · Boss 直聘投递"标签匹配算法"策略
- **原理**：招聘平台用推荐算法匹配候选人与 JD；你的标签 = 你被推给哪些 HR 的信号。
- **模式(GOOD)**：看大厂热门实习岗 JD 上打了什么标签，就给自己打什么标签；期望岗位只选"产品经理+产品运营"（运营兜底降维）；期望城市选全国提高匹配；写好在线简历后用"分享"功能自查 HR 视角；打招呼话术 3 秒内突出最大优势（学历好写学校、双非写大厂实习+方向），不抄模板、不纯"嗨你好"。
- **反模式**：期望薪资乱填、照片敷衍、只发"能聊一聊吗"、已读不回就放弃（应真诚+感情感化，HR 多是同龄人）。
- **与 skill 关系**：§7 现有"定向自我介绍钩子"只覆盖面试侧，本单元补"投递侧算法匹配"，**新增**。

### L3-N2 · 反问"三不三可"精确话术
- **原理**：到反问环节评估已基本定调，反问是礼仪节点不是翻盘点；问错 = 给面试官负面联想或心理暗示。
- **模式(GOOD · 三可问)**：①岗位具体职责和方向（JD 宽泛，合理）②对候选人期待（侧面探结果）③何时给面试反馈（无关紧要）。
- **反模式(BAD · 三不问)**：①"我有什么可优化的地方吗"→心理暗示，可能把通过改不通过；②战略/宏大问题（如"阿里 XX 决策底层逻辑"）→给面试官找麻烦；③钱/薪资→业务面试官雷区且你可能过不了。
- **与 skill 关系**：行动清单已有"反问用高质问法，禁问官网可查"，本单元把"三不三可"**具体化、可背诵**，**新增话术层**。

### L3-N3 · "面试就是编"的包装姿态（与 skill 红线校准）
- **原理**：大厂也是草台班子，真实工作流常不合理；面试时须用完美产品思维结构重新包装真实经历，不讲"团队是草台班子"。
- **模式(GOOD)**：用五步结构（团队目标→数据分析→定位问题→产品动作→结果）套任何事，讲得完整闭环。
- **反模式(BAD)**：照实讲不合理流程（一定挂）；一问一答像被拷打（进不了大厂）；被动把面试官当老师。
- **⚠️ 与 skill 红线校准**：课程"编"= **用结构重构真实经历，不是伪造数据/事实**，与 skill「不编造答案」一致。但课程建议"时间线可调、运营经历可去掉"**踩在红线边缘**——本 skill 立场：**项目真实性 > 包装**，写进简历的必须能答上来（见 L0 L1-07 候选人想删项目的印证）。包装只重构表达，不篡改事实与时间线。

### L3-N4 · 二次分润 ROI 逻辑（教学反例 · BAD 标杆）
- **原理**：拉新促活发放的作者激励/补贴是额外成本，需优先从全量分润中回收，ROI 才能 ≥1。
- **模式(GOOD 讲法)**：先讲作者收入两层（①活动奖励：发文/阅读阶梯 ②基础广告分润）→ 再讲为什么调分润（降低新作者拿钱门槛）→ 生态池/二次分润本质是先扣回补贴成本、剩余再分润，保证 ROI≥1。
- **反模式(BAD)**：把二次分润讲成"调节作者收入/生态平衡"（候选人原话，被面试官判没听懂）；或根本讲不清（"逻辑明白但讲不出来"）。
- **与 skill 关系**：作为** BAD 标杆案例**补入 L3，配合 `候选人_数据口径审计总表.md` §5.3 翻车记录，**新增教学反例**。

### L3-N5 · 深度/开放题"参与方-痛点-异见"框架
- **原理**：创新/战略开放题考思路不考答案；人尽皆知的回答 = 低分。
- **模式(GOOD)**：①搞清楚参与方（谁、什么行业）②从平台/用户/商家各方拆痛点与利益 ③行业/用户/平台痛点分层 ④给出**不一样的、没听过的观点**（如京东做外卖不只"给主站引流"）。
- **反模式(BAD)**：答常识、回避公司弊端（如百度走下坡路可直说）、给一个数字不拆层（数据拆解题至少拆 2–3 层）。
- **与 skill 关系**：与 §7「五层拆透法/业务链路拆解法」同源但更口语、可背诵，**新增话术层补充**。

### L3-N6 · 秋招/提前批投递时机策略
- **原理**：面试官招人初期最亢奋、要求最高；面多了疲劳，标准从"拔尖"降到"逻辑 OK"。
- **模式(GOOD)**：非流程化招聘建议秋招开始后 2–3 周投，避开最亢奋期；提前批没准备好别去（面评能查到，留差评得不偿失）；用中小公司做面试练习练兵。
- **反模式(BAD)**：等秋招正式开才练（来不及）；没准备好冲提前批留差面评。
- **与 skill 关系**：§10 T4 能力画像/复盘未覆盖"投递节奏"，**新增时机策略**。
