# 逐题复盘标准模板（用户提供的 verbatim 提示词）

> 本文件是 `pm-interview-prep` 做 T3 面试复盘时的**逐题输出模板**。
> 来源：用户 2026-07-29 直接提供的复盘提示词（原样保存，不润色）。
> 用法：用户发来面试记录（逐字稿或录音转写后）→ 加载本模板 → 严格按五段式输出，逐题用规定格式，事实/分析/推测三色区分，原话 100% 保留，禁用表格。
> 红线：不编造项目细节、不把团队成果默认归因个人、分析必须在原话之后。

---

以下是我的真实面试记录。请只根据记录中明确出现的内容复盘，不要补充不存在的项目细节，不要猜测面试结果。

我需要的是“有原话证据的逐题复盘”，不是泛泛概述，也不要使用表格。

请从第一性原理出发：先判断面试官为什么问这个问题，他想验证什么能力；再结合我的原话，判断我的回答是否真正回应了问题。

请按以下结构输出：

1. 本次面试整体判断
用 3—5 句话说明：
- 这场面试最核心在考什么；
- 我的整体表现如何；
- 最主要的加分点；
- 最主要的失分点。
每个判断都必须基于后文的具体问答证据。
- **结果预判硬规则（v0.35）**：在写「整体表现 / 是否通过」类判断时，**只**允许基于两类证据：①**硬伤**——面试官投入追问轮次最多的那道题上，有无思维断点（答非所问、被连续追问后仍未接住）；②**硬约束**——到岗时间 / 实习时长 / 届别这类能否说死的硬项。⚠️ **软信号一律不作结果依据**：面试官主动讲了多少业务、反问环节态度、语气、面试总时长、是否展开聊团队——xTool（判偏负→实际通过）与快手（判偏正→实际未过）两场方向完全相反，已证无预测力。凡「他好像对我印象不错」类揣测必须标【推测】，且不得作为通过依据。

2. 本次面试的底层逻辑
说明：
- 面试官围绕哪些能力连续追问；
- 每组问题的提问顺序说明了什么；
- 这个岗位真正需要候选人证明什么；
- 我的回答最终给面试官留下了哪些能力信号。
必须区分：
- 【事实】：记录中发生了什么；
- 【分析】：基于提问和回答做出的判断；
- 【推测】：证据不足时才使用，并明确标注“推测”。

2.5 面试官问题清单（单一板块，先整理后分析）
在「3. 逐题复盘」逐题深挖**之前**，必须先单独输出一张**面试官问题地图**：按面试时间顺序，把面试官问过的所有问题（含追问合并）逐条列出，格式为「题 X：{面试官问题的精简表述}」。
- **只整理、不分析**：本板块不写判断、不写原话摘录、不写归因，纯粹给出「面试官到底问了哪些问题」的完整清单，让读者先有一张全局地图，再进入逐题深挖。
- 清单题号与「3. 逐题复盘」的题号**一一对应**（清单题 X = 逐题复盘题 X）。
- 若某题含面试官多次追问，在清单里合并为一行，子问题用「/」分隔（例：「题6：手上其他 offer / 对趣丸的意愿度」）。
- 面试官主动追问纳入清单；候选人主动反问不纳入（但可在清单末单独标注反问环节，便于区分）。

3. 逐题复盘
按面试顺序分析所有重要问题。每一题必须严格使用以下格式：

### 问题 X：{面试官问题的精简表述}

- 【面试官原话】
  “摘录面试官最关键的原话。如果同一个问题追问多次，要按顺序列出。”

- 【我的原话】
  “摘录我最关键、最能代表实际回答的原话。不得改写为更通顺的版本；若原话很长，可用省略号删去无关口头语，但不能改变原意。”

- 【他真正想确认什么】
  用 1—3 句话说明该问题背后的能力验证点。

- 【回答判断】
  明确标记为：回答得好 / 回答一般 / 回答不好 / 无法判断。

- 【为什么】
  必须紧贴原话解释：
  1. 我具体回答到了什么；
  2. 我具体遗漏、回避或答偏了什么；
  3. 这会如何影响面试官对我的能力判断。

- 【下次如何优化】
  只给针对本题的改进。先说明回答结构，再给一段“示范回答”。
  示范回答不能编造我的经历、数据或职责。记录中没有的信息必须写为【待补充】。

4. 最关键的三道强题与三道弱题
每道题都要包含：
- 面试官原话；
- 我的原话；
- 为什么它是强题或弱题；
- 它反映出的能力信号。

5. 最关键的三个准备动作
每项都必须明确：
- 需要补齐的真实材料或能力；
- 它对应面试中的哪道具体问题；
- 一周内如何完成；
- 完成后的验收标准。

输出规则：
- 不使用表格。
- 不要把团队成果默认归因于我个人。
- 不要编造项目细节。
- “面试官原话”和“我的原话”必须来自记录；不确定时请标注“转写可能有误”。
- 原话摘录要保留必要上下文，避免断章取义。
- 分析必须在原话之后，不能只有抽象判断。

6. 五项技术横向复检（v0.31 单遍·复用 §3 逐题证据）

> **本段紧跟 §5 之后、同一份文档内完成。不复盘第二遍、不重新读原始逐字稿、不出独立文件。**
> 全部五项技术只基于 §3 已写好的逐题块（面试官原话 / 我的原话 / 他真正想确认什么 / 回答判断）做横向串联与标注，**不要回头处理原始记录**——这是 v0.31 把「双文档双遍」合并为「单遍单文件」的关键：同一批证据只抽一次，复检只做串联与标注。

#### 6.1 对话语境卡（a）
- 对全部**通用行为题**，基于 §3 已写的「他真正想确认什么」+ 题序，做单题语境卡：前序话题是什么 / 面试官为何在此刻问 / 该题第一句应落在哪。
- 检查有无「把通用题改写成项目题」的偏差（通用题答成项目深挖 = 错位）。
- **识别补救窗口题**：上一题留下负面印象后紧跟的、最易正面回答的题（软着陆点）——若有，标出「上一题 → 本题」衔接关系，并判断用户是否接住。

#### 6.2 答题卡纯度（b）
- 对关键题做双卡对照：**字面任务卡**（题目表面问什么）vs **语境卡**（6.1 推的该位置该完成什么）。
- 标记「只命中一张卡」的题。
- **判断铁律**：评价一道题答得好不好，**先看「它在这个对话位置该完成什么任务」，再看内容质量**。双卡齐全 = 真强题；只命中字面 = 内容好但位置错。

#### 6.3 回声防火墙（c）
- 对 §3 各题「下次如何优化·示范回答」段做回声检测：
  - **新增句少于三句 = 属回声**，只能当复述用、不能当答法用。
  - **任何「替用户总结的抽象句」必须标「待确认」**，不得默认采用（红线：AI 不生产新的话）。
  - 最干净的示范是「**素材搬运**」型：把答对的题的素材搬到答错的题上，零编造。

#### 6.4 独立参考回答（d）
- 挑**最强 1 题 + 最弱 3 题**（共 4 题，改动收益最大），**先不看用户回答、独立写标杆第一句 + 结构**，再与 §3 已写判断比对差距。
- 复用 §3 已写的题面与判断，不重读原文。

#### 6.5 商业化资金流账本（e）
- 凡 §3 已抽数值涉及 **ROI / 收入 / 成本 / 利润 / eCPM / 分润 / 补贴 / 结算**，建账本，六字段 = 付款方 / 收款方 / 角色 / 口径 / 周期 / **主体**。
- **必须查「数字归谁」**：客户的 ROI？平台的收入？创作者的分润？这是 §3「数字准不准」之外的第二层检查（主体性）。

#### 6.6 复检交付要求
- 以上五项作为本文档 §6 一节，与主文档同文件交付。
- 在 §1 头部加一句交叉指针：「五项技术横向复检见 §6」。

7. 复盘必查·两条跨场 P0 红线（v0.35）

> 两条由真实复盘回填确立的跨场失败模式（趣丸 HR 二面 + 快手一面两次实证）。每次复盘**必须逐题扫描**逐字稿是否命中，命中即标红并写入 §5 准备动作。

#### 7.1 P0-①「X 个月以上」永久禁用
- **现象**：用模糊区间回答时长 / 到岗类题（"实习 3 个月以上""至少几个月""看情况"）。
- **后果**：模糊时长 = 稳定性硬伤信号，已两次实证（趣丸 HR 二面失败归因 + 快手一面复发）。
- **正确答法**：必须给**下限 + 上限两个确定数**（如"保证 4 个月、可延长到 6 个月"）。
- **复盘中**：凡逐字稿出现"X 个月以上 / 至少 X 月 / 看情况"类模糊时长表达，一律标红。

#### 7.2 P0-② 抗压 / 强度题必须明确表态
- **现象**：面试官讲强度 / 压力后，用"更猛啊""哦 OK""能接受"轻轻带过，不表态。
- **后果**：抗压 / 强度往往是该团队的筛选口径（快手明说"靠量取胜、男 PM 要皮实"、12 小时强度即现场考点的硬门槛）。不表态 = 主动放弃该维度。
- **正确答法**：明确说"我了解并能接受" + **一句自己证明过的高压场景**（课程 / 项目 / 实习里的具体事例）。
- **复盘中**：凡抗压 / 强度类题回答只接不表，一律标红，并在 §5 补"如何准备一句真实抗压事例"。
