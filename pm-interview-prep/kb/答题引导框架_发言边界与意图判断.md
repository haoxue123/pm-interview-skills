# 答题引导框架 · 发言边界与意图判断（用户个人 OP）

> **来源**：用户 2026-08-03 口述提炼，从**第一性原理**出发的答题操作程序（Operating Procedure）。
> **用途**：本 Skill 在「引导用户回答未知题 / 模拟面试(T6) / 复盘(T3)」时的**统一引导协议**——先控边界、再判意图、确认业务、回到「数据优先于感受」。
> **定位**：本 OP = `SKILL.md §5 通用拆解法四步` 的用户个性化精修版，新增「发言边界控制」+「数据优先于感受」两个锚点，不冲突、可叠加。

---

## 一、四步 OP（开口前 → 开口后的固定顺序）

1. **控制发言边界**（元步骤，最优先）：开口前先定「我能答什么 / 我不能答什么」。
2. **判断问题意图**：这题到底在考什么——项目指标？开放思维？动机？还是某项能力指标？
3. **确认业务范围**：把问题锚定到具体业务/场景，不空谈、不泛泛。
4. **回到「数据优先于感受」铁律**：任何结论先用数据/口径支撑，再给判断；不用「我觉得/我感觉」起头。

> 顺序不可颠倒：边界没控住就开口，容易编造；意图没判准就答，容易跑题；业务没确认就讲，容易空泛；最后必须用数据铁律收口。

---

## 二、发言边界控制（元步骤 · 最优先）

**边界判定口诀**：「这事我真实做过 / 算过吗？做过 → 讲；没做过 → 承认边界 + 迁移，绝不编。」

| 我能答（直接讲、如实说） | 我不能答 / 不编（一律承认边界） |
|---|---|
| 项目指标（闭卷 P0 数字 + 七要素口径） | 没算过的指标硬编 |
| 真实经历（STAR 真实动作） | 没经历过的方法论杜撰 |
| 真实动机 / 业务背景 | 美化过度、夸大参与度 |
| 边界外的领域（GA4/广效通未用过等） | 假装熟练 |

- 不能答时的标准动作（与 `SKILL.md §11 红线·不编造` 同源）：**承认边界 + 类比 + 秀方法论**，而非编。
- 示例：「GA4 我没实操过，但我用 SQL + Excel 透视表做过数据监控，它的事件驱动模型我理解是……」

---

## 三、问题意图判断（按题型分类 · 内容表格）

> 这是用户要求落进「内容表格描述」的核心表。引导答题 / 模拟面试时，先据此判题型，再决定策略。

| 问题类型 | 我能答什么（直接讲） | 我不能 / 慎答什么 | 应对策略 |
|---|---|---|---|
| **项目指标题**（CTR / ROI / 天数 / 样本等） | 闭卷 P0 数字 + 七要素口径 | 没算过的指标硬编 | **基本秒答**——这是最强项，开口即带口径 |
| **为什么做这个项目**（动机 / 背景） | 真实动机、真实业务背景 | 美化过度、编造动机 | **如实说**，直接讲真实原因，不绕 |
| **开放性项目题**（"如果让你做 X 你怎么设计"） | 对应能力指标（决策深度 / 数据口径 / 业务了解…） | 跑题、空谈方法论 | 先锁定「这题在考我**哪项能力**」，再展开对应素材 |
| **纯开放思维题**（无项目依托） | 框架 + 日常积累的真实案例 | 凭空杜撰、无案例支撑 | 先思考（承认需想）→ 调日常积累 → 框架先行 |
| **业务范围确认题** | 已知公司 / 岗位业务 | 瞎编业务数据 | 锚定到具体业务 / 场景再答 |

**用户自述规律（已提炼）**：
- 项目指标题 → 基本秒答（闭卷 + 口径在手）。
- 开放题 → **比较难，自己要先思考**；且思考依赖**日常积累**——这是长期项，临场补不了，平时多攒案例/框架。
- "为什么做项目" → 直接如实说。
- 开放性项目题 → **必是在考某项能力指标**，先判准考哪项，再对应展开。

---

## 四、核心铁律：数据优先于感受

- 任何结论**先给数据 / 口径，再给判断**；禁用「我觉得 / 我感觉 / 应该吧」单独起头。
- 与 `B 数据口径`维度同源：数字必须脱口七要素（口径 / 样本 / 对比基准 / 归因 / 置信度）。
- 感受可作补充，但**不能替代数据成为主论据**。
- 例：❌「我感觉这个活动效果应该不错」→ ✅「活动 CTR 从 15% 提到 25%（基准=搜索品专整体大盘），所以判断样式优化有效」。

---

## 五、用户自述难点（诚实标注，不回避）

- **开放题「比较难，自己要先思考」**：承认需要思考时间；卡顿时给「我组织一下」再答（见 `C 维度防御`），不硬编。
- **开放题的思考依赖日常积累**：平时多攒案例 / 框架，面试才能调用——这是长期项，不是临场能补。
- **不确定后续题型时 → 留白，不臆测**：宁可说「这块我目前理解是 X，不确定是否还有其他考法」，也不编后续。
