# 企业业务四卡

给定「公司 + 岗位（+ JD）」，产出一份 1500–2700 字的四卡文档：这个行业怎么赚钱 / 他靠什么赚钱 / 这个岗为什么存在、卡在链路哪一环 / 他会怎么追我的简历 / 我该问他什么。**不预测题目，只搭业务地基。**

## 1 六条不做

1. 不押题、不出题单、不写「可能考察」「预计会问」。
2. 不预测面型、不判通过率、不打分、不画雷达图。
3. 不写「岗位业务知识讲解五段式」扫盲长文（老方案里这节占 24%–35%，是负担主源）。
4. 不写逐字稿大全，也不写排比式话术脚本：用于朗读的块（`【必背】` + `> `）合计 ≤ 全文 45%。
5. 不读 `pm-interview-prep/kb/`（76 个文件那套），也不复制它的 A–F 人设、面型库、真题库。
6. 不出 PDF；不做 1–3 万字深度研究报告。

## 2 触发与移交

**该触发**：给了公司+岗位要备面 / 问「这家公司靠什么赚钱」「这个部门做什么」「这个岗为什么存在」「它在链路里干什么」「这个行业怎么赚钱」「你对这个岗位怎么理解」「为什么投这个行业」「JD 怎么拆」「简历会被怎么问」「反问该问什么」/ 明说「四张卡」「轻量准备」。

**该移交**：

| 用户说的 | 交给 |
|---|---|
| 「研究一下这家公司」「帮我做个研究」「写个报告」 | `hv-analysis`（1–3 万字报告体） |
| 「帮我模拟面试」「练一下」「给我打分」 | `interview-coach` |
| 「复盘一下这场」「我把逐字稿发你」 | `pm-interview-prep` |
| 「我只想知道这个数字的口径」 | 直接答，不必出卡 |

**路由切分**：说「了解一下这家公司」时，看语境——**面试语境走本技能**，研究语境走 hv-analysis。

## 3 输入与缺失处理

**必需**：公司名、岗位名。**可选**：JD 原文、面试轮次、面试官角色、距面试时间。

| 缺什么 | 怎么办 | 禁止 |
|---|---|---|
| 无 JD | 搜实习僧/Boss/牛客同公司同岗 JD；仍无 → 模块3 降为「岗位名反推 3 条能力〔推导〕」，卡数 3，总字数下调 300 | 凭岗位名编 6 条要求 |
| 无轮次 | 按「一面业务面」默认 | 追问超过 2 个问题 |
| 部门查不到 | 走 §12 第 1 条三级降级 | 用「行业普遍」填空 |

## 4 六条判断（不改）

1. **信息差不在「题」，在「业务」。** 题目空间无限（6 场实测漏测 48.9%、主线命中 1/6），业务结构有限、可穷尽、可迁移。
2. **病根是把「理解材料」和「作答材料」混在一份文档里。** 本技能在版式层就劈开：要念的稿走 `【必背】` 红卡，要看的走表格与短标题。
3. **模块2 不是预测，是可穷尽的追问。** 追问路径由你简历里自己写下的结论决定（你写「增收 1.1 亿」，就只能问分子/分母/样本/基准），不由市场决定。
4. **模块1 的「考察方向」不许靠猜。** 只能从「业务痛点 → 他要什么样的人」推出来。
5. **「你对岗位的了解」和「为什么投递」是同一张卡的两种问法。** 前者＝这个岗为什么存在、卡在链路哪一环、做好做砸什么样；后者＝行业在变、公司最痛、我卡那一环，各说一句。所以卡片分三层（行业/公司/岗位），**再加一张竞品表收口**。
6. **竞品不是公司层的一格。** S2 要求竞品「2–3 家 + 用户为什么选/弃」共 4 项信息，而三层卡只给公司层 1 格（≤55 字）——配额装不下，竞品就在成品里消失了（实测只剩 45 字）。所以模块1 必须有第四段：**独立竞品表，4 行，末行是「自己」**。
   - **口径纪律**：平台总 GMV 份额各家口径打架到离谱（同一平台能差 3 倍：抖音 9.8% / 20% / 24% → 快手 5% / 6% / 14.2%）。**一个都不用**，只用品类内有明确口径的数字。
   - **禁**：给任何「念的话」（排比三句 / 因果链 / 一句话版本）。已试三次，用户全部判「说出口还是别人的话」。本技能只产**看的材料**，开口问题归 `interview-coach` 陪练。

## 5 执行流程

### S0 定坐标
抽 4 个变量（公司/岗位/JD/距面试时间），缺项按 §3 处理，**追问 ≤2 个**。回显一行「本次目标：<公司>·<岗位>｜四卡 ≤2700 字｜不押题」，**直接开工，不等确认**。

### S1 读事实源（只读 2 个文件）
- 必读：`[工作区]\记录\候选人_简历_结构化.md`（含「数据口径卡」8 个数字的 ✅/⚠️）。
- 选读：`[工作区]\记录\项目经历压力面试拷打清单.md`，**只取对应项目的「防守答法」列当素材**，不搬运十大拷打逻辑全文、不重写。
- 硬禁止：`pm-interview-prep/kb/**`。
- 产出内部清单「候选追问点 × 口径状态」，不进最终文档。

### S2 企业调研（≤8 次检索，到 8 次必须停）

| 组 | Query 模板 | 要拿到 |
|---|---|---|
| 公司 | `<公司> 2026 营收 财报`、`<公司> 最新动态 2026` | 今天在增长/守成/转型 + 一个近期具体动作 |
| 行业 | `<品类> 市场规模 2026`、`<品类> 价格带 集中度 白牌` | 只服务行业层：规模/增速、CR5、白牌占比、价格带 |
| 竞品 | `<公司> 竞品 对比`、`<A> vs <B> 用户评价` | 2–3 家 + 用户为什么选/弃 |
| 岗位 | `<公司> <岗位> 面经`、`<公司> <部门> 招聘` | 部门职责原话、轮次、真实问法 |

**竞品这组查到的东西直接进 1.4 竞品表，不许压成公司层一格。** 只取 3 类：它靠什么赢、用户为什么选它、它抢不到哪块。平台总 GMV 份额（`抖音电商市占率` 这类）**不进表**——口径打架，一问就崩。

**来源分层**：L1 官方（官网/年报/官方 JD）→ 可当【事实】；L2 权威媒体研报 → 【事实】须带年月；L3 用户侧（应用商店/黑猫/小红书/知乎）→ **只能当「用户为什么选或弃」「痛点」的证据**；L4 百科/自媒体 → 只当线索，须回 L1/L2 验证。

**只记**能进 5 格的信息 + 1 条用户侧抱怨，产出 8–12 条带 `〔L层级·YYYY-MM〕` 的内部 bullet，**不进最终文档**。

### S3 填三层卡，再加竞品表

**第一层 · 行业**（≤4 行，每格 ≤55 字）：钱从哪来（单价/频次/决策轻重）→ 结构（集中度、白牌占比、价格带）→ 现在在变什么（渠道/需求/供给，择一讲透）→ 在目标平台的特殊性（用户结构是否匹配）。**「记住一句」不单列**，被谁抢那件事交给 1.4 竞品表。
**硬规则：行业层必须带 ≥2 个行业级数字**（市场规模/增速/CR5/价格带/线上渗透率）。一个都没有 = 没做行业调研，退回 S2 重查。

**第二层 · 公司**（≤3 行）：靠什么赚钱（收入结构百分比）→ 今天什么处境（增速/利润/口径变化）→ 靠什么赢、被谁挤。

**第三层 · 岗位**（4 行，必须全填；这是「你对岗位的了解」的全部答案）：
- **为什么存在**：从「公司处境 → 谁的什么指标没人管 → 所以要这个人」倒推。句式：因为<什么处境>，而<谁的什么事>没人管，所以要有人<承担什么>。**禁复述 JD**。
- **卡在链路哪一环**：`上游 → 本岗（动词） → 下游 → 验收指标`，四段都要有名词，缺一段就是没想清。
- **手里有什么权**：先写**没有**哪些权（流量/预算/技术/人事），再写只能靠什么撬，最后点出因此哪项能力是硬能力（不是软素质）。
- **做好和做砸**：各一句。砸的那句必须写失败模式（变成发券机器 / 变成活动执行 / 商家薅完就走），这才是深度。

**hv 只取三问**（不调用 hv-analysis、不出报告）：纵向「<年>选择<做了什么>，导致今天<处境>」→ 公司层第 2 格；横向 2–3 家（强在哪/用户为什么选或弃）→ 公司层第 3 格；交汇一句「今天在<位置>，所以这岗最痛的是<…>」→ 岗位层第 1 格。

**第四段 · 竞品表（表格再好也得能落地到「谁在抢」，这段是行业层的出口）**

4 行，顺序固定 **抖音 → 拼多多 → 线下 + 品牌 → 自己**（同赛道的第 1、2 家按实际换，但「自己」永远在最后一行）：

| 列 | 必填什么 | 反例 |
|---|---|---|
| 对手 | 平台名 / 渠道类型 | 「竞争对手很多」 |
| 靠什么赢 | 1–2 个品类内数字或明确的机制 | 「流量大」「价格低」（没机制） |
| 它抢不到哪块 | 一句判断，必须能被本岗的动作接住 | 「各有优势」（等于没写） |

**四条硬规则**：
1. **必须含「自己」一行**，且该行第 3 列写**自己的缺口**（例：抢不到品牌预算）——这一格直接接住岗位层「为什么存在」。
2. 第 3 列不许空、不许写「各有优势」。判据：这句话能不能被本岗某个动作回答，答不了就是废话。
3. **数字只用品类内口径**（份额/价格带/集中度），不写平台总 GMV 份额；来源弱（转载站、无原始口径）的数字宁可不要，改定性。
4. 行内不复述三层卡已有内容；3 行之内说完，不展开成段落。

**禁止词**：`可能考察`、`预计会问`、`大概率`、`据了解`、`业内普遍认为`、`建议了解`、`应该是`。
**禁止动作**：① 把 JD 原句换个说法当「为什么存在」；② 写成立时间/融资/估值/员工数/荣誉/使命/文化口号；③ 只写公司不写行业，或只写行业不写岗位。

### S4 模块2 简历深挖（单位是「简历里的一句结论」，不是「一段实习」）

**S4-0 先定攻击面（2026-10-29 新增，跳过这步必返工）**：动笔前先写一句「这个岗的面试官只会从哪个矛盾往下挖」，再从简历池里挑能接住这个矛盾的事实。**事实不许换，攻击面必须换。**

- 反例（真实事故）：7 份四卡（众联世纪/影石/快手/枫叶/海尼/转转/海辰）深挖卡的锚点池是同一批 8 个事实（CTR 5 次、周结 4 次、提案 3 次…），只换了标题和措辞，用户一眼判「这些问题都没变过」。根因是打分规则（有数字且口径未闭合 =3 分）让同几个事实永远排最前，JD 只影响 +2 和排序，不影响选哪条。
- 正例（海尼 FDE）：同一个 85% 事实，从「分母是多少」换成「剩下 15% 不用的人你管了吗」；同一个百度周结事实，从「这是改配置吧」换成「一套机制怎么套六条业务线」。事实没变，问题是新的。
- **单份内**：5 张卡的首问里 ≥3 张必须直接冲「本岗核心矛盾」（写在模块1 岗位层「做好和做砸」那格），不许 5 张全在查数据口径。

**打分**：有数字且口径 ⚠️ 未闭合 =3；有数字已闭合 =2；纯计数/纯动作 =0；JD 出现同一能力词 +2；无对照组/无基准 +1；用了「主导/推动/设计」+1。

**四条配额（不许平均分配）**：
1. 取分最高 4–6 条，**同一段实习 ≤2 条**（3 段实习不做 2/2/2）。
2. ≥1 条来自与目标 JD 最近的那段；无 JD 时取最近一段。
3. **四类攻击面各至少 1 条**：数据口径 / 归因对照 / 贡献边界 / 迁移或失败。
4. 作业帮计数类默认 0 分，除非 JD 明写运营/SOP/流程。
5. **跨文档不重复**：出稿前翻一遍 `[工作区]\记录\*业务四卡.md`，若本份 5 张卡里有 ≥2 张与上一份的「首问」语义重复（只是换了数字），必须换攻击面重写，不许换标题交差。

**分级**：A 级 2–3 张（带 200–260 字稿，标【必背】）= 被追问最多、答错代价最大的题，必须背熟；B 级 2–3 张（首问 + 第一句 + 一句避雷，80–110 字，标「只看不背」）= 一问就过、看一眼就够。

**能力标注（必填）**：每张卡在首问下加一行 `**考察**：<能力1> ＋ <能力2>`，能力名只许从模块3 拆出的 JD 能力族里取（如方案设计 / 推动落地 / 数据判断 / 方法论沉淀 / 岗位迁移），**禁写「沟通能力」「学习能力」这类泛词**。四张卡合起来必须覆盖四类攻击面：数据口径 / 归因对照 / 贡献边界 / 岗位迁移。

**追问链固定 3 问**：首问（数字/结论）→ 追①（分子/分母/样本/基准）→ 追②（归因对照或贡献边界）。

**稿子四句结构**：①我在<公司><项目>负责<角色>，解决的是<问题>（≤40 字）②当时<约束>，我判断<决策>（≤70）③所以我做了<动作>，代价是<我和谁换了什么>（≤70）④结果<数字>，口径<…>；我现在的看法是<一句复盘>（≤80）。

**避雷点公式**：「别说『X』——说了他必追『Y』，而你手上没有 Y；改说『Z』。」（≤45 字）

### S5 模块3 拆 JD

1. 只留「动词+对象」句，删公司介绍与福利。
2. 能力族先合并：沟通/协调/推动/跨部门 → 推动力；分析/数据/复盘 → 数据判断；搭建/设计/输出 → 方案设计。
3. 一句含两个不同能力动词（如「需求分析 + 原型设计」）→ 拆两条。
4. **上限 6、下限 4**；先写「这个岗的核心产出是<…>」，落不到核心产出的一律降级进「缺口」不出卡。
5. 「熟悉/了解/优先」不单独出卡，写进对应卡的「缺口 + 兜底」。
6. 每卡只给 4 行框架，**禁止 100 字以上成段稿**（稿只属模块2）。

### S6 模块4 反问

业务向 2（★必带，答完能修正企业卡某一格，须写出格名）；团队向 2（○，答完知道「进来 30 天先做成什么」）；成长向 1–2（○，问能力路径不问评价）。每问 ≤50 字、能直接念、带具体名词。

**「不建议问」三条判定**：① 信息型（官网/JD/HR 能查到）② 是否型且不改决策（加班/转正/薪资/团队会不会调整，交 HR）③ 交评价权（我今天表现怎么样/您觉得我合适吗）。文档里保留 **1 个 ✕ 示例**让规则可见。

### S7 落版 → 质检 → 交付
写 `[工作区]\记录\<公司>_<岗位>_业务四卡.md` → 跑 §8 十三条 → 不合格就地改，**只出一版** → 转飞书（§11）→ 回链。

## 6 四卡模板

### 6.0 版式铁律（md2feishuxml.py 实测约束）

1. 全文档只有一个 `# `（→ 飞书 title）；四张卡用 `## 1`–`## 4`；卡内用 `### 1.1`；**序号手写**，转换器原样保留、不自动编号。
2. **给人念的答案走 `【必背】` 块（红卡）；面试官问法、一句话判断走 `> `；给人看的走表格/短标题。**
3. 标签**只能在段首**，且之后空一行；`- 【事实】` 无效；`> 【必背】` **无效**（不会变红卡，只是普通引用）。
4. **颜色分工**：`【必背】` 红 = 要背的稿（全文只 2–3 处）；`【分析】` 橙 = 避雷点/推导；`【事实】` 蓝 = 带来源的数据；`【横幅：…】` 蓝 = 文档头。**避雷点禁用 `【P0】`**——与 `【必背】` 同为红色，会全篇飘红、失去指向性。
5. **禁用 `- 【业务痛点】` 这类自定义字段**：转换器 `FIELD_SET` 只认 12 个固定名，其余降级成普通段落。自定义字段一律写 `**字段名**：内容`。**不改共享脚本。**

**三套预设**：A 深挖为主 = A3+B2+JD4+反问6；B JD 为主 = A2+B3+JD6+反问8；**C 最省 = A2+B2+JD4+反问6（三层卡 + 竞品表版实测 2676）**。

## 8 质检 13 条（出稿前必跑）

1. `^# ` 行数 = 1；`## ` 编号 1–4 连续。
2. 中文正文 1500–2700 字（三层卡版）。
3. 模块1 三层齐全：行业 ≤4 行、公司 ≤3 行、岗位 4 行；单格 ≤55 字；1.4 竞品表 ≤180 字；整块 ≤800 字。
4. 模块1 命中黑名单词（成立/融资/估值/员工数/荣誉/使命/愿景/企业文化/股价）→ 不合格。
5. 行业层 ≥2 个行业级数字且带〔L2〕；岗位层「为什么存在」与 JD 原文不得有连续 8 字重合（=复述 JD 即不合格）；「卡在链路哪一环」必须含上游/本岗/下游/验收四段。
6. 全文 grep `可能考察|预计会问|大概率|据了解|业内普遍|建议了解|应该是` → 命中即不合格。
7. A 级稿在 `【必背】` 块内且 200–260 字；B 级卡无 `【必背】` 块；`【必背】` 全文只出现 2–3 次。
8. 可朗读部分（`【必背】` 块 + `> ` 块）字数 ≤ 全文 45%。
9. 稿内 grep `首先|其次|综上|此外|值得一提的是|值得注意的是|不难看出|有效地|进一步|从而|赋能|抓手|打法` → 命中即不合格。
10. 每份稿第一句含「我在」，且含 ≥1 个口语锚点（当时/其实/说白了/我印象）。
11. 模块2 每卡必须有「考察」行，能力名与 JD 能力族对得上、无泛词；模块3 每卡严格 4 行、无 100 字成段；模块4 每问带 ★/○/✕ 且不含 加班/转正/薪资/团队会不会/我今天表现。
12. 每个数字后 20 字内出现口径词（分子/分母/样本/基准/口径）或显式 ⚠️。
13. **竞品表**：4 行齐全、3 列非空、**末行必须是「自己」**；每行第 3 列含「抢不到 / 弱 / 触达不到」类判断，写「各有优势」=不合格；数字均带品类口径（份额/价格带/集中度）；**出现平台总 GMV 份额即不合格**；全文只有这一张竞品表，且文档里不得再出现「投递理由按这三层说」这类指向不存在内容的索引。
14. **深挖卡新鲜度**：5 张卡首问中 ≥3 张直接冲模块1 岗位层写的「做砸」那句；且与上一份四卡的首问语义重复 ≤1 张。做不到就是换皮，退回 S4-0。

## 10 红线

1. 不编事实：查不到写〔未查到·检索日〕，不写「据了解」。
2. 简历数字只从事实源取，不新增、不改写；⚠️ 未闭合的口径必须显式带 ⚠️。
3. 面试稿只能从「简历原文 + 拷打清单防守答法」改写，**禁新增事实**。
4. 三层卡任一字段超帽 = 违约，不是「稍微长一点」；岗位层 4 行缺一行 = 不合格。
5. 不把 B 级卡写成可朗读段落。
6. 只出一版，不产出 v2/v3。
7. 不追加「附：业务扫盲」「附：行为题 8 类」这类章节。
8. 飞书建文档失败要明说原因，不静默跳过；**禁止 PDF**。
