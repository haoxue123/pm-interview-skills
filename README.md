# 产品经理面试准备技能集

两个用于产品经理 / 产品运营面试准备的 WorkBuddy Skill。

## 技能一：company-biz-prep（企业业务四卡）

单岗位面试「四张卡」生成器：企业与岗位卡（行业→公司→岗位三层）/ 简历深挖卡 / 岗位 JD 匹配卡 / 反问卡，全文 1500–2700 字。重心是行业与岗位理解，不押题。

触发词：企业调研、业务认知、为什么选我们、竞品怎么比、JD 怎么拆、四张卡、轻量准备。

## 技能二：pm-interview-prep（产品经理面试准备专家）

第一性原理 · 可成长系统。知识库以「原理+模式+反模式+人设状态」为原子单位，每次面试经验反哺系统成长。

- T3 面试复盘（逐题原话证据 + 五项横向复检）
- T9 面试前准备（岗位调研 + 业务讲解 + 前置高风险维度）
- T6 Adaptive 模拟面试（评分→诊断→推送闭环）
- A–F 人设状态机（跨会话持久化）
